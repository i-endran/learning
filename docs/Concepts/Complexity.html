The Big Picture: P vs NP

A high-level overview of computational complexity classes. This defines the boundaries of what computers can solve efficiently versus what they can only check efficiently.

Deterministic (Standard Computer)

A machine that follows one single path of execution. If faced with a choice, it must check each option one by one. This represents real-world computers.

Non-Deterministic (Theoretical Magic)

A theoretical machine that can "branch" into multiple paths simultaneously. If faced with a choice, it checks all options at the exact same instant.

Euler Diagram: The Assumption that P ≠ NP

P Easy

Polynomial Time. Problems that can be solved reasonably fast by a real computer (e.g., Sorting, Multiplication).

If you double the input, the time takes a predictable step up.

NP Checkable

Nondeterministic Polynomial. Problems where the solution is hard to find, but easy to verify if you are given one (e.g., Sudoku, Factoring).

Includes all of P.

NP-Complete The Hardest

The "Ultimate" problems in NP. If you find a fast shortcut for one, you solve them all. (e.g., Traveling Salesperson, 3-SAT).

The bridge between P and NP.
