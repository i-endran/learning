🧠 Computer Science Interview Cheat Sheet

Goal: Rapid review of core Computer Science concepts for technical interviews.

1. Operating Systems (OS) 🖥️

Core Concepts 📚

  • Processes & Threads: Process states, PCB, context switching, multithreading, concurrency.
  • Scheduling Algorithms: FCFS, SJF, RR, Priority, MLFQ — know tradeoffs (throughput, turnaround, starvation).
  • Synchronization: Race conditions, critical section, mutex, semaphores, monitors, deadlock (4 conditions, avoidance via Banker’s algorithm).
  • Memory Management: Paging, segmentation, virtual memory, page replacement (LRU, FIFO, Optimal), TLB.
  • File Systems: Inodes, allocation (contiguous, linked, indexed), journaling.
  • System Calls & Kernel/User Mode.

One-liners 💡

  • Process states: A process moves through states like new, ready, running, waiting, terminated.
  • PCB: Process Control Block — OS data structure storing a process's metadata.
  • Context switching: Saving and restoring CPU registers/state to switch execution.
  • Deadlock: Situation where processes wait forever due to circular resource holds.
  • Virtual memory: Illusion of large contiguous memory using disk backing and paging.
  • LRU/FIFO/Optimal: Page replacement policies.
  • System call: Controlled interface for user programs to request kernel services.

Common Interview Questions ❓

  • Difference between process vs thread?
  • How does context switching work?
  • What happens on a page fault?
  • How does the OS handle deadlocks?

2. Database Management Systems (DBMS) 💾

Core Concepts 📚

  • Data Models: Relational model, schema, ER diagrams.
  • SQL Essentials: SELECT, JOINs, GROUP BY, subqueries, indexes.
  • Normalization: 1NF → BCNF, anomalies.
  • Transactions: ACID properties, Commit/Rollback, 2-Phase Locking.
  • Concurrency Control: Locks, deadlocks, isolation levels.
  • Indexing: B+ Trees, Hash Indexing.
  • Storage: WAL (Write-Ahead Log), checkpoints.

One-liners 💡

  • ACID: Atomicity, Consistency, Isolation, Durability.
  • Index: Data structure (B+ tree) to speed up lookups at cost of write speed.
  • Normalization: Reducing redundancy to prevent anomalies.
  • WAL: Change log ensuring durability before applying to main data.

Interview Topics 📝

  • Why use normalization?
  • How do indexes speed up queries?
  • Difference between SQL & NoSQL?
  • Inner, left, right joins?

3. Computer Networks (CN) 🌐

Core Concepts 📚

  • OSI vs TCP/IP Layers.
  • Application Layer: HTTP/HTTPS, DNS, SMTP, FTP.
  • Transport Layer: TCP (3-way handshake), UDP.
  • Network Layer: IP addressing, routing, ICMP.
  • Data Link: MAC, ARP, switching.

Networking Concepts 🔌

  • DNS resolution process
  • NAT, Subnetting
  • Difference between switch, hub, router
  • CDN, load balancing, reverse proxy

One-liners 💡

  • TCP: Reliable, connection-oriented. UDP: Unreliable, connectionless, fast.
  • DNS: Phonebook of the internet (Domain → IP).
  • HTTPS: HTTP + SSL/TLS.
  • Bandwidth vs Latency: Width of pipe vs Speed of water.

4. Distributed Systems 🔗

Core Concepts 📚

  • CAP Theorem: Consistency, Availability, Partition tolerance (choose 2).
  • Consensus: Paxos, Raft.
  • Consistency Models: Strong, eventual, causal.
  • Replication & Sharding: Lag, horizontal vs vertical scaling.
  • Fault Tolerance: Leader election, heartbeats.

One-liners 💡

  • Scalability: Horizontal (more machines) vs Vertical (better machines).
  • Sharding: Splitting data across nodes.
  • Message Queues: Kafka/RabbitMQ for decoupling.

Array, Linked List, Stack, Queue, HashMap, Tree, Graph, Heap, Trie, Union-Find.
