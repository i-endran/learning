Graph Algorithms Crash Course

A quick reference guide for mastering BFS, DFS, Dijkstra, Bellman-Ford, Topological Sort, and Union-Find for competitive programming and technical interviews.

1. The Core Algorithms: At a Glance

Algorithm Analogy Key Behavior Best For
BFS Ripple in a pond Explores layer-by-layer (Wide). Shortest Path (Unweighted)
DFS Maze Solver Dives deep, backtracks at dead ends. Reachability, Cycles, Islands
Dijkstra Smart GPS Explores "cheapest" path first. Shortest Path (Weighted +)
Bellman-Ford Careful Accountant Checks every edge repeatedly. Shortest Path (Weighted +/-)
Topological Sort Assembly Line Linear ordering of dependencies. Task Scheduling, Dependency Resolution
Union-Find Networking Cables Connects components dynamically. Connectivity, Kruskal's MST

2. Implementation Templates (Python)

BFS (Breadth-First Search)

Logic: Use a Queue. FIFO (First-In, First-Out). 
from collections import deque

def bfs(graph, start):
    queue = deque([(start, 0)]) # Store (node, distance)
    visited = set([start])
    
    while queue:
        node, dist = queue.popleft() # POP LEFT
        # Process node...
        
        for neighbor in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append((neighbor, dist + 1))

DFS (Depth-First Search)

Logic: Use Recursion (Implicit Stack). 
def dfs(graph, node, visited=None):
    if visited is None: 
        visited = set()
    
    visited.add(node)
    # Process node...
    
    for neighbor in graph[node]:
        if neighbor not in visited:
            dfs(graph, neighbor, visited)

Dijkstra's Algorithm

Logic: Use a Priority Queue (Min-Heap). Always pop the smallest cost. 
import heapq

def dijkstra(graph, start):
    pq = [(0, start)] # (cost, node)
    dists = {node: float('inf') for node in graph}
    dists[start] = 0
    
    while pq:
        d, u = heapq.heappop(pq) # POP SMALLEST
        
        if d > dists[u]: continue # Skip stale entries
        
        for v, weight in graph[u]:
            if dists[u] + weight < dists[v]:
                dists[v] = dists[u] + weight
                heapq.heappush(pq, (dists[v], v))
    return dists

Bellman-Ford Algorithm

Logic: Brute force relaxation (V-1 times). Handles negative weights. 
def bellman_ford(n, edges, start):
    dist = [float('inf')] * n
    dist[start] = 0
    
    for _ in range(n - 1): # Repeat V-1 times
        for u, v, w in edges:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
    return dist

Topological Sort (Kahn's Algorithm)

Logic: DAG only. Count In-Degrees. Nodes with 0 in-degree go first. 
from collections import deque

def topological_sort(n, edges):
    in_degree = [0] * n
    graph = {i: [] for i in range(n)}
    
    for u, v in edges:
        graph[u].append(v)
        in_degree[v] += 1
        
    queue = deque([i for i in range(n) if in_degree[i] == 0])
    topo_order = []
    
    while queue:
        node = queue.popleft()
        topo_order.append(node)
        
        for neighbor in graph[node]:
            in_degree[neighbor] -= 1
            if in_degree[neighbor] == 0:
                queue.append(neighbor)
                
    return topo_order if len(topo_order) == n else [] # Empty if cycle detected

Union-Find (Disjoint Set Union)

Logic: find() with Path Compression, union() with Rank. Nearly O(1). 
class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [1] * n
        
    def find(self, p):
        if self.parent[p] != p:
            self.parent[p] = self.find(self.parent[p]) # Path Compression
        return self.parent[p]
    
    def union(self, p, q):
        rootP = self.find(p)
        rootQ = self.find(q)
        
        if rootP != rootQ:
            # Union by Rank
            if self.rank[rootP] > self.rank[rootQ]:
                self.parent[rootQ] = rootP
            elif self.rank[rootP] < self.rank[rootQ]:
                self.parent[rootP] = rootQ
            else:
                self.parent[rootQ] = rootP
                self.rank[rootP] += 1
            return True
        return False

3. Complexity Cheat Sheet

Algorithm Time Complexity Space Complexity Notes
BFS O(V + E) O(V) Standard linear scan.
DFS O(V + E) O(V) Space depends on recursion depth.
Dijkstra O(E log V) O(V) Log factor comes from Heap operations.
Bellman-Ford O(V × E) O(V) Slowest, but handles negative weights.
Topological Sort O(V + E) O(V) Only works on Directed Acyclic Graphs (DAGs).
Union-Find O(α(N)) ≈ O(1) O(V) Ackermann function (inverse) is very slow-growing.

4. LeetCode Strategy Guide

  • ✅ Unweighted Shortest Path? → Use BFS. Do not use DFS.
  • ✅ Weighted Shortest Path? → Use Dijkstra.
  • ✅ Searching / Connectivity? → Use DFS (Easier to write recursively).
  • ✅ Negative Weights? → Use Bellman-Ford.
  • ✅ Course Schedule / Prerequsites? → Use Topological Sort.
  • ✅ Grouping / Connected Components? → Use Union-Find.
  • ✅ Grid/Matrix Input? → Use direction array: [(0,1), (0,-1), (1,0), (-1,0)].
