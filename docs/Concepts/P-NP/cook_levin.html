The Cook-Levin Theorem

The breakthrough that started it all. In the early 1970s, Stephen Cook and Leonid Levin independently discovered that one specific problem is the "master key" to all NP problems.

The First NP-Complete Problem

Before this theorem, we knew there were hard problems, but we didn't know if they were related. Cook and Levin proved that the Boolean Satisfiability Problem (SAT) is NP-Complete.

Theorem: Every problem in NP can be reduced to the Boolean Satisfiability Problem (SAT) in polynomial time.

This means if you can solve SAT efficiently (in Polynomial time), you can solve every problem in NP efficiently.

What is SAT?

Given a boolean logic formula, is there a way to set the variables (True/False) so that the entire formula evaluates to True?

Example: (A OR B) AND (NOT A OR C) AND (NOT B OR NOT C)

This seems simple, but for large formulas with thousands of variables, checking all combinations takes billions of years.
